# Roadmap detail

maintained milestone list. This directory is reserved for **longer-form**
planning documents that would clutter the root roadmap file — e.g.
detailed milestone retrospectives once M0/M1 complete, or deep-dive
planning docs for a specific milestone.

Status: empty by design until the first milestone retrospective is
written.
